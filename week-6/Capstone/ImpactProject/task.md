# Impact Project

**Why it matters:**
A portfolio that never gets a second project goes stale and stops proving anything new. The difference between a class artifact and a career platform is one simple habit, set up now while you still remember how everything works.

**Brief:**
1. Write down, in a few lines, exactly where your next case study will go and the steps to add one (reuse the Week 2 three-beat shape, problem, what you did, what came of it).
2. Name the next real piece of work you intend to add, and set yourself a concrete reminder to add it (a calendar nudge, a recurring note).
3. Keep your Claude Project, it already knows your voice, stack, and identity kit, so the next case is a short conversation, not a rebuild.

**Deliverable:**
The short "how to add the next case" note + the named next piece + evidence of the reminder set

**Pass / revise:**
- There's a concrete "how to add the next case" note, not a vague intention.
- A specific next piece of work is named with a real reminder set.
- The build context (Claude Project) is preserved so future updates are cheap.
