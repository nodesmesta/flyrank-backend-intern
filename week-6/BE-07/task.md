# Connect to an AI API

## Full assignment is attached as PDF document.
Add one endpoint to your API that asks an AI model for a judgement — and returns an answer your code can actually trust.

"Integrate an LLM." doesn't mean "build a chatbot." They mean something smaller and more useful: one step in a workflow where a person reads something and makes a call — classify this message, tidy this job title, pull fields out of this receipt — done in code instead. That's what you build this week, and you pick the job yourself. The model call is thirty lines; the real work is making it trustworthy — a schema for every answer, a real timeout, retries that know when to stop, and eight test cases that prove it works. Any language welcome; resources cover JavaScript and Python. Two free model providers, no credit card, ever.
