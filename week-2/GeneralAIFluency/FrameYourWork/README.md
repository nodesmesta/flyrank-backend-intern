# Week 2 — Frame Your Work

## The Process

This folder documents the **Frame Your Work** assignment — the process of turning an abstract idea into a framed case study using AI as an interviewer, not an author.

### Step 1: Set the Voice Card

**File:** [`data/voice-card.md`](./data/voice-card.md)

Five words that define how I want to sound across all my portfolio copy:

> Direct, technical, deliverable, visionary, original.

This is the standing instruction I give to Claude before any drafting.

---

### Step 2: Interview — Asset Guard

**File:** [`data/case-study-asset-guard.md`](./data/case-study-asset-guard.md)

**The project:** Asset Guard — a SaaS platform that helps people and organizations detect stuck assets (property, equipment, IP, inventory) and get a clear productivity score with improvement steps.

**The interview format:** Claude asked one question at a time:
1. What problem does this solve?
2. Who is it for?
3. What did you actually build?
4. What came of it?

I answered honestly, including that nothing is built yet — it's still at the design phase.

**The 3 beats result:**

| Beat | Summary |
|------|---------|
| Problem | People own stuck assets that sit idle — no tool tells them if it's productive |
| What I did | Designed Asset Guard: upload PDF → score → automated live monitoring |
| What came of it | Problem validated, architecture designed, build is next |

## Key Takeaway

The skill this week is not writing case studies. It's using AI to **interview** yourself until the real story comes out, then **editing hard** so it sounds like you — not a generic AI bio.
