## Market Overview

IT Asset Management software centralizes discovery, lifecycle tracking, license compliance, and financial oversight of all IT assets (hardware, software, and cloud) from a single platform.

**Three factors determine the right ITAM tool:**
1. Discovery coverage (agent vs. agentless)
2. Lifecycle governance depth
3. Integration with existing IT Service Management workflows

## Key Features: Must-Have List

**Foundational (must-have):**
- Automated discovery — Continuously detects devices, applications, and cloud resources
- Asset normalization — Cleans and standardizes asset data, prevents duplicates
- Centralized asset inventory — One unified platform
- Asset Lifecycle Management — Request → acquisition → operation → depreciation → retirement
- Compliance Management — Software entitlements, usage, policy alignment
- Reporting and analytics — Dashboards and reports
- Integrations ecosystem — ITSM tools, identity providers, endpoint management, cloud systems

**Advanced (nice-to-have):**
- CMDB (Configuration Management Database) — Maps relationships between assets and services
- Advanced automation — Approval processes, compliance remediation, lifecycle transitions
- AI-powered features — Contextual recommendations, risk highlighting

## Evaluation Criteria (per vendor)

1. Core ITAM capabilities (discovery, inventory, lifecycle, reporting, compliance)
2. Deployment models (cloud, on-premise, hybrid)
3. Integration ecosystem (ITSM, directory services, cloud platforms)
4. User feedback (Gartner Peer Insights, G2, Capterra)
5. Implementation effort (time-to-first-inventory)
6. Support & enablement

## ITAM vs SAM vs HAM

- **ITAM** — Umbrella discipline. Full lifecycle of all IT assets (hardware, software, cloud). Focus: visibility, control, cost optimization, compliance
- **SAM (Software Asset Management)** — Deeper control over software usage and vendor contracts. Focus: audit risk, license compliance, SaaS sprawl
- **HAM (Hardware Asset Management)** — Device tracking, lifecycle planning, depreciation. Focus: refresh programs, physical inventory

## 2-4 Week Pilot Plan

- **Week 0 (prep, 2–3 days):** Define scope, success criteria, baseline metrics
- **Week 1 (inventory):** Connect 2–3 discovery sources, build first inventory
- **Week 2 (lifecycle + compliance):** Track 1 real lifecycle flow, set up license tracking for 1–2 vendors
- **Weeks 3–4 (automation + reporting):** Add alerts, create 2–3 dashboards, validate data quality

## Common Use Cases

1. **Hardware lifecycle management** — Tracking ownership, location, condition, lifecycle status
2. **Software license compliance** — Installed applications, SaaS usage, license entitlements
3. **Remote workforce visibility** — Real-time visibility into endpoints and cloud resources
4. **Audit readiness** — Structured asset data, lifecycle history, operational context
