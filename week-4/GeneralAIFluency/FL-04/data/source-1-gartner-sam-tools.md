## Market Definition

Software asset management (SAM) tools aim to decipher the complex and ever-changing world of software licensing. Core capabilities include:

- **Discovery** — Interrogate networks to find physical, virtual and cloud platforms
- **Normalization** — Consolidate datasets to resolve duplicated/conflicting records
- **Reconciliation** — Correlate contract/purchase records with inventory data → Effective License Position (ELP)
- **Optimization** — Track software usage, identify over-deployed and under-consumed licenses
- **Reporting** — Management dashboards, compliance tracking

SAM tools provide data on software utilization, identify over deployed and under consumed licenses, reharvest and reallocate licenses, track renewals and financials for purchased software, and proactively identify software misconfiguration.

## Key Features (Mandatory)

1. **Share software asset information** — Central system of record across organizational functions
2. **Conduct discovery** — Find physical, virtual, and cloud platforms
3. **Capture entitlements** — Analyze contracts and purchases
4. **Normalize data** — Resolve duplicated/conflicting records
5. **Identify platform consumption** — Capture configuration data
6. **Optimize entitlements** — Track changes and balance spending
7. **Govern** — Allocate licenses, automate workflows
8. **Reconcile** — Create Effective License Position (ELP)

## Peer Lessons Learned (July 2025)

1. **Audit Current SAM Processes** — Identify inefficiencies and requirements before tool selection
2. **Run POCs** — Assess compatibility, compare UI for ease of use
3. **Train End Users** — Maximize SAM tool adoption and usage
4. **Ensure Foundational Readiness** — Data cleanup and network setup before deployment
5. **Engage Implementation Partner** — Roll out the tool in phases
