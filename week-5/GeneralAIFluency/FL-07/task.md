# Build the Agent

**Why it matters:**
This is Checkpoint 1, the MVP. An agent that completes its core job end to end with at least one live tool connection is the artifact everything else in your submission orbits.

**Brief:**
1. Build on the platform you chose in FL-06. Start with the narrowest version of the core job and get one full end-to-end run working before adding anything.
2. Connect at least one real tool or data source: an MCP server or connector, your files, a knowledge base, or an external service.
3. Keep a build log: what broke, what you changed, what you cut from the spec and why. Deviating from the spec is normal; document it.
4. When the core job works, record one raw, unedited screen capture (about 2 minutes) of a successful end-to-end run.

**Deliverable:**
The working agent, the build log, and the raw run capture posted in the submissions.

**Pass / revise:**
- Agent completes its core job end to end without mid-run hand-editing
- At least one live tool, file, or data connection in use
- Matches the FL-06 spec, or deviations documented with reasons
- Build log shows real iteration, not a clean retroactive story
- Run capture unedited, showing the full loop from request to result
